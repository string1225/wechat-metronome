# 架子鼓练习助手

一个给鼓手日常练习用的微信小程序：节拍器、基本功、套鼓律动。

## 当前方向

- 三个入口依次为节拍器、基本功、套鼓律动；启动默认节拍器，底部固定播放控制。
- 基本功依次选择类别、具体练习、小节数、谱面；练习选项直接展示。小节数和套鼓分轨位于谱面上方。
- 标准动次打次、踩镲／底鼓／军鼓分解练习，以及一小节示范、一小节跟打。
- 一小节预备拍，4／8／16小节或持续循环，分轨静音，独立鼓组与节拍器音量。
- 同一行切换节奏网格和五线谱；基本功默认节奏网格。五线谱固定使用用户提供的谱位图，附图例。
- 点击「放大」进入专注视图，支持横屏。记住速度、练习和音量设置。
- 基础节拍器：4/4、40–220 BPM、输入速度、Tap tempo、开始/停止、重拍视觉提示。
- 基本功包含单击和节奏组合：右左手提示、细分网格和当前落点高亮。
- 连续练习支持从 8 分到 32 分再回到 8 分，每种 4 小节。
- 练习内容由 `utils/patterns.js` 数据驱动，后续新增练习只需要增加一个模式数据。
- 音频使用 `wx.createWebAudioContext`，预先合成底鼓、军鼓、踩镲和 click/rim 的 PCM 缓冲。
- 声音设置中提供音量增强，并为多声部叠加预留音量空间。
- 当前环境不支持 WebAudio 时，保留视觉提示。
- 声音按音频时钟提前120毫秒调度，同一落点所有声部共用时间戳；JS定时器只负责调度唤醒和视觉更新。
- 停止、离开页面或切换练习会取消已排队声音和视觉回调。

## 标准动次打次

4/4 拍，八分踩镲：踩镲落在 `1 & 2 & 3 & 4 &`；底鼓在1、3拍，军鼓在2、4拍。「动」包含底鼓与踩镲，「打」包含军鼓与踩镲。

分解练习只改变参与声部，听奏交替的跟打小节只保留启用的节拍器。左右手标记以常见右手主导打法为例。

## 固定五线谱位置

按用户于 2026-09-30 提供的鼓谱图统一，不再区分流派。线、间均从下向上数；切换网格和五线谱只改变显示，不改变节奏或音色。手部符干向上，底鼓符干向下。

| 乐器 | 位置 |
| --- | --- |
| 底鼓（大鼓） | 第一间 |
| 三桶鼓 | 第二间 |
| 军鼓（小军鼓） | 第三间 |
| 二桶鼓 | 第四线 |
| 一桶鼓 | 第四间 |
| 叮叮镲 | 第五线 |
| 踩镲 | 上加一间 |
| 吊镲／强音镲 | 上加一线 |

当前套鼓练习使用闭合踩镲、军鼓、底鼓；其余鼓件按参考图保留在图例中。鼓类用实心符头，镲类用叉形符头。

## 已内置练习

### 单击练习

- 8分音符单击
- 三连音单击
- 16分音符单击
- 5连音单击
- 6连音单击
- 7连音单击
- 32分音符单击

### 节奏练习

- 前八后十六：16 分底板第 1/3/4 格落槌。
- 前16后八：16 分底板第 1/2/3 格落槌。
- 8分切分：16 分底板第 1/2/4 格落槌。
- 8分前附点：16 分底板第 1/4 格落槌。
- 8分后附点：16 分底板第 1/2 格落槌。

### 连续练习

- 连续打：8分、三连、16分、5连、6连、7连、32分，再从32分回到8分，每种4小节。
- 空1小节：同样的上行下行流程，但每种练习之间插入1小节空拍，只保留四分参照。

## 验证与交付

- `node --test tests/practice.test.js`：检查节奏落点、时值、预备拍、循环、听奏交替、谱位映射及音频同步与停止行为。
- 微信开发者工具导入仓库根目录；真机检查鼓音、播放高亮、横屏、后台停止和蓝牙设备延迟。
- AppID 以 `project.config.json` 为准。完成变更后先提交并推送，再使用 `miniprogram-ci` 预览。
- 二维码、检查结果与临时工具放在 `dist/`，不提交、不打包。上传私钥保留在仓库外，`.key`、`.pem` 也已排除。
